# Arquipoza

Web de un estudio de arquitectura con portfolio de proyectos, galería de bocetos, seguimiento de obras e información de contacto.

🌐 **[Visitar la web](https://arquipoza.handyocean1.chatgpt.site)** — Acceso público desde cualquier navegador.

El proyecto original utiliza **.NET 8, Orchard Core, SQLite y Bootstrap**. La versión online está adaptada a **ChatGPT Sites**, conservando el diseño y los contenidos, con imágenes optimizadas en WebP.

Incluye búsqueda y filtros de proyectos, fichas de detalle y carruseles. Los formularios abren la aplicación de correo del visitante; la versión online no incluye el panel de Orchard.
